# Пространственная эконометрика, домашнее задание №1

Проект по курсу пространственной эконометрики. Исследуются пространственные эффекты в выручке
продуктового ритейла: моделируется розничный товарооборот магазинов сети «Пятерочка» по
локальным рынкам России.

Работа выполняется коллективом авторов из пяти человек. Все участники работают над общим
исследованием и несут совместную ответственность за постановку задачи, сбор и подготовку
данных, оценивание моделей, написание текста отчета и его защиту. Персональное закрепление
разделов не выделяется: текст, код и результаты готовятся и проверяются совместно.

## Постановка исследования

Зависимая переменная - логарифм среднемесячного розничного товарооборота в расчете на один
магазин сети в населенном пункте. Пространственная единица - населенный пункт, в котором сеть
представлена не менее чем тремя магазинами. Размерность панели: 933 объекта и 26 месяцев
с января 2023 по февраль 2025 года.

Исследование разделяет два механизма, которые одновременно формируют выручку локального рынка.
Агломерационный механизм поднимает выручку за счет близости к крупным и экономически активным
территориям. Конкурентный механизм ее снижает, поскольку близко расположенные торговые точки
делят один поток покупателей. В непространственной регрессии эти механизмы не различимы, а
пространственные модели разделяют их через коэффициент пространственного лага зависимой
переменной и разложение предельных эффектов на прямые и косвенные.

Полная постановка, перечень независимых переменных, матрицы пространственных весов, гипотезы
и открытые вопросы к преподавателю приведены в [`Proposal/README.md`](Proposal/README.md).

## Анализ

Анализ выполняется в `Analysis/analysis.R` на языке R. Используется стек семинаров курса:
`sf` для пространственных данных и проекций, `spdep` и `rgeoda` для матриц пространственных
весов и статистик автокорреляции, `spatialreg` и `splm` для пространственных регрессий, `plm`
для панельных моделей без пространственной структуры, `ggplot2` и `patchwork` для графики.

Графики и карты сохраняются в `Analysis/assets` и оттуда подключаются в текст отчета. Пакеты R
зафиксированы через `renv` в `renv.lock`. Восстановление окружения и запуск анализа с сохранением
полного вывода в `Analysis/analysis.log`:

```bash
Rscript -e 'renv::restore()'
Rscript Analysis/analysis.R > Analysis/analysis.log 2>&1
```

Подготовка данных выполняется на Python: выгрузки Росстата приходят в формате xlsx, который
удобнее разбирать `pandas` и `openpyxl`. Окружение управляется через `uv`, зависимости
зафиксированы в `pyproject.toml` и `uv.lock`:

```bash
uv sync
```

Для участников, у которых нет `uv`, зависимости продублированы в `requirements.txt`:

```bash
python -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt
```

Файл `requirements.txt` генерируется из `uv.lock` и руками не правится. После любого изменения
зависимостей его нужно пересобрать:

```bash
./Scripts/export_requirements.sh
```

## Подготовка данных

Итоговый файл `Data/settlement_panel.parquet` собирается конвейером предобработки `preprocessing`
из десяти шагов в `src`:

```bash
uv run python -m src.run_pipeline preprocessing
```

Без `uv` та же команда запускается через `python` из окружения с `requirements.txt`. Шаги,
продолжение с середины и журнал запусков описаны в `Runs/README.md`, колонки итоговой панели -
в `Data/README.md`.

Данные, собранные собственным парсингом, лежат в `Parsing`. Каждый внешний источник занимает
отдельную подпапку, рядом с результатом обязательно лежит `SOURCE.md` с описанием происхождения
данных и условий использования. Готовые выгрузки Росстата к парсингу не относятся и лежат
в `Data`.

## Отчет

Текст отчета готовится в `Paper/main.tex`. Компиляция в pdf без временных файлов LaTeX:

```bash
./Paper/compile.sh
```

Скрипт собирает документ в `tmp/paper-build`, копирует готовый файл в `Paper` и удаляет
временную папку. Готовый pdf для сдачи выкладывается в `Export`.
