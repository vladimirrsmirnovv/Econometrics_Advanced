# Конвейеры

Каждый конвейер описан файлом `<название>.jsonl`: одна строка - один шаг с номером, модулем
из `src`, описанием, входными и выходными файлами. Шаги выполняются строго по порядку, первый
упавший шаг останавливает запуск.

```bash
uv run python -m src.run_pipeline preprocessing            # все шаги
uv run python -m src.run_pipeline preprocessing --from 8   # продолжить с шага 8
```

Каждый запуск дописывает в `<название>.history.jsonl` статус шагов, длительность и контрольные
суммы SHA-256 выходных файлов. Совпадение сумм между запусками подтверждает воспроизводимость.
Журнал локальный и в репозиторий не попадает.

## preprocessing

Предобработка данных: из первичной панели магазинов сети, выгрузок Росстата и координат GeoNames
собирается итоговая панель `Data/settlement_panel.parquet`.

1. `rosstat_inflation` - индексы потребительских цен по субъектам из xlsx в csv.
2. `rosstat_wages` - номинальная зарплата по субъектам помесячно.
3. `rosstat_unemployment` - безработица по субъектам: скользящие кварталы и годы.
4. `rosstat_population` - численность городских населенных пунктов на 1 января 2024 года.
5. `regions` - сопоставление 67 регионов сети субъектам Росстата по коду ОКАТО.
6. `shops_clean` - проверка и очистка панели «магазин - месяц».
7. `settlements` - склейка написаний населенного пункта, отбор пунктов с 3+ магазинами, агрегирование.
8. `geography` - координаты и расстояния до Москвы и центра субъекта.
9. `population` - численность Росстата для населенных пунктов сети.
10. `panel` - дефлирование выручки, региональные показатели, итоговые проверки.

Шаги 8 и 9 останавливаются, если сопоставление сомнительно, и выкладывают список в
`Data/Interim/*_to_review.csv`. Решение записывается в `Data/Manual` с обоснованием, после чего
запуск продолжается с этого шага.
