# Финальный отчёт о прогнозировании РТО

Единственная финальная версия отчёта:

- PDF: [Прогноз_РТО_финальный_отчёт.pdf](output/pdf/Прогноз_РТО_финальный_отчёт.pdf).
- Исходный LaTeX: [Прогноз_РТО_финальный_отчёт.tex](Прогноз_РТО_финальный_отчёт.tex).

11 страниц А4, включая титульную, 8 таблиц и 3 рисунка. Содержимое LaTeX и PDF
при переименовании сохранено побайтно. Предыдущие версии, их архивы и временные
копии удалены. `assets`, `tables` и `sources` содержат материалы финального отчёта.

## Сборка

Из каталога `Improving_Gradient_Boosting`:

```powershell
& 'Forecasting/report/compile_report.ps1'
```

Скрипт выполняет два прохода `pdflatex` и сохраняет PDF в `output/pdf`.
Для подключения таблиц используется отдельный временный файл совместимости;
исходный LaTeX не изменяется. Временные материалы сборки и визуальной проверки
находятся в `../../tmp/pdfs/final_forecast_report`.

## Проверка

Установите зависимость проверки в используемую среду Python:

```powershell
& 'Forecasting/.venv/Scripts/python.exe' -m pip install pypdf
```

```powershell
& 'Forecasting/.venv/Scripts/python.exe' -X utf8 'Forecasting/report/verify_report.py'
```

`quality_checks.json` содержит контрольные суммы финальных файлов, результаты
проверки ссылок, таблиц и рисунков. Все 11 страниц готового PDF проверены визуально.
Проверка работает и в чистой копии репозитория без временных журналов сборки:
неизменность PDF подтверждается сохранённой контрольной суммой.

`prepare_report.py` воспроизводит таблицы и рисунки по сохранённым результатам
эксперимента. `evidence_manifest.json` фиксирует исходные материалы;
`tables/submission_registry.csv` хранит реестр конкурсных оценок.
