# Семь следующих мартовских смесей

Уточнение 11 октября: соревнование завершено; баллы относятся к основному финальному мартовскому сету для рейтинга. Точный охват магазинов не подтверждён. Для конкурсного выбора основной критерий — итоговый балл; локальная валидация служит диагностикой. Варианты выбраны после обратной связи этого теста.

Варианты расположены по рекомендуемому порядку проверки. Сначала папки 01–04. Папки 05–07 — резерв: локально они проигрывают текущему итоговому ориентиру в обоих контрольных месяцах. Текущий ориентир — исходная смесь с WX только у XGBoost, 90,80 итоговый балл при сохранённом порядке предыдущих отправок.

Распакуйте архив с сохранением папок и отправляйте CSV `test.csv` из выбранной папки. Общий ZIP не отправляется. Ни один из семи прогнозов не дублирует ранее подготовленные варианты, включая отличие только в переносах строк или числовой точности записи.

В 01,02,07 используется та же исходная meta-формула, что у варианта с 90,80; меняется только версия ещё одной модели. В 03,04,05,06 состав фиксирован: исходные CatBoost и LightGBM, XGBoost с WX. В 03 дополнительно исключён LightGBM приростов, как в исходной ветви no_weak.

Правило с порогом 1,08 взято из исходного решения: если максимум / минимум прогнозов больше 1,08, берётся медиана; иначе обычное среднее. В 03 правило применяется к трём моделям, в 04 — к четырём. В 05 используется обычное среднее, в 06 — exp(mean(log(1+prediction)))−1. Порог и веса не подбирались. Пространственные модели — только ранее обученные учебные WX, полные исходные числа деревьев сохранены.

01 и 02 улучшают оба месяца относительно исходного ансамбля и ориентира с 90,80. 03 улучшает среднюю ошибку, но ухудшает январь. 04 улучшает январь, но ухудшает февраль. 05–07 проигрывают ориентиру в обоих месяцах и оставлены как необязательные проверки переноса на март.

Все месяцы уже использовались, составы проверяются после обратной связи итоговой проверяющей системы. Это ретроспективные эксперименты, не новый слепой тест; мартовские баллы новых вариантов при подготовке были неизвестны. Первоначальные критерии, FINAL_DECISION, модели и эконометрическая часть не меняются. Нельзя выводить преимущество ансамбля только из баллов его отдельных участников.

В каждом файле 18657 строк, столбцы new_id,rto, уникальные исходные ID, положительные конечные прогнозы, размер <1 МБ. Проверены SHA источников, точное восстановление чисел после записи, отсутствие повторов и CRC архива. В соревнование автоматически не отправлялись.
