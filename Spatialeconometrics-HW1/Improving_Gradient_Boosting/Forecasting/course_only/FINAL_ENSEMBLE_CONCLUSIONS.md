Прогнозы №04 и №05 различаются: медиана абсолютной относительной разницы 0,08827%, 90-й процентиль 0,19285%, максимум 5,66874%. Из различия прогнозов нельзя определить взаимодополняемость ошибок без истинных РТО марта.

В пределах исходного CatBoost, XGBoost WX и двух вариантов каждого LightGBM почти вся сетка из четырёх составов и пяти исходных правил уже подготовлена и оценена. Два gated-варианта без LGBdiff совпадают с уже существующими прогнозами и не требуют повторных посылок.

Перспективные дальнейшие проверки, без новых пространственных конструкций и подбора весов:

1. Равновесное обычное и логарифмическое средние двух лидеров №04 и №05. Это две гипотезы; улучшение не установлено. Применяются операции, уже имеющиеся в исходном ноутбуке.
2. Те же равновесные средние №04 с прежней meta-смесью на 90,82 либо с №08 на 90,82. Первая сохраняет часть прогноза исходного LightGBM уровней, вторая уменьшает участие LightGBM приростов через смешивание с составом без этой модели. Оценивать новый прогноз непосредственно; не усреднять баллы.
3. Оставшаяся исходная комбинация с обычным средним XGBoost WX + LightGBM уровней WX + двумя исходными моделями. Она закрывает сетку, хотя наблюдаемые результаты средних не дают сильного основания ждать выигрыша.
4. Если продолжать обучение, добавить в ансамбль альтернативные WX-компоненты с другой из уже используемых учебных матриц W kNN6/kNN12. Сейчас мартовские версии используют выбранную W для каждой модели. Альтернативную мартовскую версию нужно обучить с теми же исходными параметрами и полным числом деревьев, а затем сравнить равновесную смесь с текущими компонентами. Это продолжение существующего WX из курса, а не новое произвольное сглаживание.
