# Материалы работы

- `Пространственная-эконометрика-ДЗ1.pdf` - отчет. Часть I - исследование пространственных эффектов
  в выручке магазинов сети «Пятерочка», часть II - прогноз розничного товарооборота на март 2025 года
  с пространственными признаками.
- `Пространственная-эконометрика-Презентация.pdf` - презентация к защите, 25 слайдов.
- `Пространственная-эконометрика-Речь.pdf` - речь к части I; часть II Владимир рассказывает по своему усмотрению.
- `analysis.R` - код эконометрического анализа части I.
- `forecast_spatial_boosting.ipynb` - код прогноза части II: полное обучение четырех градиентных
  бустингов с пространственными лагами признаков $WX$ и итоговое объединение прогнозов. Запускается
  из этой папки, прогноз сохраняет в `forecast_march_2025.csv`.
- `Data/settlement_panel.parquet` - итоговая панель «населенный пункт - месяц» для эконометрических
  моделей: 933 населенных пункта, 26 месяцев (январь 2023 - февраль 2025 года).
- `Data/russia_regions_complete_simplified.geojson` - границы субъектов России для карт.
- `Data/train_2.csv` - исходные данные соревнования X5 Group: помесячная выручка и характеристики
  18 657 магазинов сети, источник для панели и для прогноза.
- `Data/settlement_coordinates.csv` - координаты населенных пунктов из базы GeoNames для матрицы
  пространственных весов прогноза.
