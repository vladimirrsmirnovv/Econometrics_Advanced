# Данные

Исходные выгрузки не перезаписываются. Производные наборы сохраняются под отдельными именами.
В каждой подпапке лежит `SOURCE.md` с источником, разметкой нужных листов и описанием рабочего csv,
в который конвейер переводит выгрузку Росстата.

## Состав

`Shops/` - первичная панель «магазин - месяц» с розничным товарооборотом и социально-географическими характеристиками магазинов сети «Пятерочка». Данные хакатона X5 Group, полученные через участие в соревновании. Период: январь 2023 - февраль 2025.

`Population/` - численность населения по муниципальным образованиям на 1 января 2024 года, Росстат. Заменяет зашумленную численность из данных сети.

`Inflation/` - индексы потребительских цен по субъектам, помесячно. Продовольственный индекс используется для дефлирования выручки.

`Wages/` - среднемесячная начисленная заработная плата по субъектам, помесячно. Единственный источник с месячной частотой.

`Unemployment/` - уровень безработицы по субъектам: скользящие кварталы, что дает помесячный ряд, и годовые данные.

Координаты населенных пунктов лежат отдельно, в `Parsing/geonames_settlement_coordinates/result`, поскольку они получены собственным парсингом, а не скачаны готовым файлом.

## Итоговый набор

**`settlement_panel.parquet`** - основной датасет исследования, собирается конвейером предобработки
(`Runs/README.md`), в R читается через `arrow::read_parquet()`.

Это сбалансированная панель «населенный пункт - месяц»: 933 населенных пункта России × 26 месяцев
(январь 2023 - февраль 2025) = 24 258 строк, 54 колонки. В панель вошли населенные пункты из 67
регионов, где сеть «Пятерочка» представлена тремя и более магазинами. Всего в них 15 683 магазина,
медиана - 6 магазинов на пункт, максимум - Москва с 1278 магазинами. По типу это 725 городов,
120 поселков и пгт, 88 сел, станиц, деревень и аулов. Состав магазинов внутри пункта за период не
меняется. Строгий вариант выборки - фильтр `store_count >= 5`, 570 пунктов.

Зависимая переменная `log_revenue_per_store_real` - логарифм средней месячной выручки одного
магазина сети в пункте, в ценах января 2023 года. Номинальная выручка переведена в реальную
региональным индексом цен на продовольствие: к февралю 2025 года он вырос на 15-27% в зависимости
от субъекта. Средняя за период реальная выручка магазина по пунктам составляет от 36 до 194 млн
рублей в месяц, медиана - 69 млн. Номинальная выручка имеет выраженную сезонность с пиком в
декабре.

Объясняющие переменные бывают трех уровней. Характеристики окружения и магазинов посчитаны по
магазинам пункта и во времени постоянны: трафик, конкуренты, инфраструктура, кассы, доли
категорий. Характеристики пункта тоже постоянны: координаты, расстояния до Москвы и центра
субъекта, численность населения от 664 человек до 13,1 млн. Показатели субъекта меняются
по месяцам: реальная зарплата и безработица. Сырые признаки сети обезличены мультипликативным
шумом, агрегирование до пункта его в основном снимает.

Постоянные характеристики повторяются во всех 26 строках пункта, поэтому для пространственной
регрессии на данных типа cross-section пункт берется одной строкой.

| Колонка | Содержание |
| --- | --- |
| `settlement_id`, `settlement_key` | номер и ключ «код ОКАТО : название : класс типа» |
| `settlement_name`, `settlement_type_class` | название как в данных сети, класс типа (город, пгт, село и т.д.) |
| `shop_region`, `region_name`, `region_okato_code` | регион в записи сети, название и код субъекта Росстата |
| `oktmo_code` | код населенного пункта в бюллетене численности, если найден |
| `year`, `month`, `period`, `time_index` | месяц наблюдения, `time_index` от 1 до 26 |
| `log_revenue_per_store_real` | **зависимая переменная**: логарифм средней выручки магазина в ценах января 2023 года |
| `revenue_per_store_real_rub` | средняя выручка магазина в ценах января 2023 года, рублей |
| `revenue_per_store_rub`, `revenue_median_store_rub`, `revenue_total_rub` | номинальная выручка: средняя, медианная на магазин, суммарная |
| `food_price_index` | цепной индекс цен на продовольствие субъекта, январь 2023 = 1 |
| `latitude`, `longitude`, `coordinate_source` | точка населенного пункта, источник: `geonames` или `manual` |
| `distance_to_moscow_km`, `distance_to_region_center_km`, `region_center_name` | расстояния по большому кругу; центр МО - Москва, ЛО - Санкт-Петербург |
| `population`, `population_source` | численность: Росстат на 1.01.2024 (`rosstat_2024`, 822 пункта) или медиана из данных сети (`shops_median`, 111 сел и станиц) |
| `population_rosstat_2024`, `population_reported_median` | оба источника численности отдельно |
| `households_median`, `foot_traffic_per_hour_median`, `car_traffic_per_hour_median` | медианы зашумленных признаков по магазинам, нули исключены как пропуски |
| `grocery_competitors_500m_mean`, `pyaterochka_stores_500m_mean` | среднее число продуктовых конкурентов и магазинов сети в радиусе 500 м |
| `pickup_points_100m_mean`, `medical_and_pharmacies_300m_mean`, `schools_300m_mean`, `public_transport_stops_300m_mean` | средние счетчики окружения |
| `checkouts_mean`, `working_hours_per_day_mean` | среднее число касс и рабочих часов; ноль касс у работающего магазина считается пропуском и в среднее не входит, часы ограничены 24 |
| `store_count` | число магазинов сети в пункте, постоянно во времени |
| `share_large_area`, `share_small_area`, `share_new_stores`, `share_old_stores`, `share_alcohol_license` | доли магазинов |
| `stores_with_revenue_jump` | число магазинов со скачком выручки более чем втрое между месяцами, для проверки устойчивости |
| `nominal_wage_rub`, `real_wage_rub`, `consumer_price_index` | зарплата в субъекте: номинальная и в ценах января 2023 года по общему ИПЦ |
| `unemployment_rate_percent`, `unemployment_rate_annual_percent` | безработица в субъекте: скользящий квартал с центром в месяце и годовая |
| `items_per_check_mean`, `cancellations_mean`, `promo_items_per_check_mean` | показатели чека: **не регрессоры**, входят в тождество выручки |

## Промежуточные и ручные файлы

`Interim/` - промежуточные результаты конвейера, пересоздаются при каждом запуске и руками не правятся. Там же появляются `coordinates_to_review.csv` и `population_to_review.csv`, если конвейер остановился на спорных сопоставлениях.

`Manual/` - решения, принятые вручную, с обоснованием в колонке `note`:

- `coordinates.csv` - `replace` заменяет точку GeoNames, если парсинг выбрал тезку, `confirm` подтверждает сомнительную точку
- `population_links.csv` - код населенного пункта в бюллетене Росстата или `none`, если пары нет

## Единицы измерения

Розничный товарооборот - рубли за месяц. Численность населения - человек. Количество домохозяйств - единиц в зоне охвата магазина. Пеший и автомобильный трафик - человек и автомобилей в час. Объекты инфраструктуры - штук в заданном радиусе. Расстояния - метры. Индексы цен - проценты к предыдущему месяцу. Заработная плата - рубли.
