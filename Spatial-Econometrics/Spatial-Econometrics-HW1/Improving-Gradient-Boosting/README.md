# Improving Gradient Boosting

Код, результаты экспериментов и финальный отчёт об улучшении прогноза РТО магазинов
«Пятёрочка» с помощью пространственных признаков.

## Финальный отчёт

- [PDF: Прогноз РТО — финальный отчёт](Forecasting/report/output/pdf/Прогноз_РТО_финальный_отчёт.pdf).
- [Исходный LaTeX](Forecasting/report/Прогноз_РТО_финальный_отчёт.tex).
- [Сборка и проверка](Forecasting/report/README.md).

11 страниц, 8 таблиц и 3 рисунка. Текст отчёта сохранён без изменений.
Исходный ансамбль получил 90,78 балла, лучший проверенный вариант — 90,83 на полном
мартовском тесте. Конкурсные оценки использовались при сравнении вариантов;
результат не является независимой оценкой на будущих месяцах.

## Структура

| Папка | Содержимое |
|---|---|
| `Audit/` | Первоначальный аудит, код и результаты проверок |
| `Forecasting/baseline/` | Неизменённый исходный ноутбук, параметры и метрики |
| `Forecasting/course-only/` | Основной эксперимент с учебными признаками WX и итоговые решения |
| `Forecasting/report/` | Единственный финальный отчёт, таблицы, рисунки и сборка |
| `Forecasting/submissions/` | CSV прогнозов, составы ансамблей, конкурсные оценки и архивы для загрузки |
| `Forecasting/results/` | Исходные проверки моделей, прогнозы и метрики по месяцам |
| `Forecasting/score-geometry/` | Проверки конкурсной метрики и дополнительные пробы |
| `Forecasting/final-forecast/` | Код подготовки, обучения и объединения мартовских прогнозов |
| `Forecasting/kaggle/` | Работа с Kaggle и воспроизведение CUDA XGBoost |
| `Forecasting/research/`, `Forecasting/research-stage2/` | История дополнительных экспериментов и диагностика ограничений |

Текущий итог описан в [Forecasting/README.md](Forecasting/README.md) и
[выводах основного эксперимента](Forecasting/course-only/FINAL_ENSEMBLE_CONCLUSIONS.md).
Рекомендации ранних этапов имеют исторический статус.

## Запуск

Команды в документации `Forecasting` выполняются из этого каталога:

```powershell
Set-Location Improving_Gradient_Boosting
python -m venv Forecasting/.venv
& Forecasting/.venv/Scripts/python.exe -m pip install -r Forecasting/requirements.lock.txt
& Forecasting/.venv/Scripts/python.exe Forecasting/check_recipe.py
```

В Linux/macOS Python среды находится в `Forecasting/.venv/bin/python`.
Полные команды экспериментов приведены в документации соответствующих папок.
Обучение моделей выполняется только при отдельном запуске этих команд.

Общие данные, географические справочники и материалы курса расположены уровнем выше:
`../Data`, `../Parsing`, `../Source`. `Forecasting/project_paths.py` разрешает пути
к этим материалам. Старые пути `Forecasting/...` в сохранённых результатах
отсчитываются от этого каталога. Исторические контрольные суммы кода относятся
к версиям на момент обучения; при переносе обновлены только пути к общим материалам.

Проверка структуры, исходного ноутбука, неизменности отчёта и 15 финальных CSV:

```powershell
& Forecasting/.venv/Scripts/python.exe verify_repository.py
```

Результаты проверки записаны в `publication_checks.json`. Дополнительно
`Forecasting/check_artifacts.py` проверяет 66 сохранённых прогнозов и их метрики.

В Git включены код, ноутбук, метрики, CSV прогнозов, документация, рисунки и финальный
PDF. Среды Python, кэши, крупные native-модели и дублирующие архивы выгрузок обучения
сохранены локально и исключены через `.gitignore`.
