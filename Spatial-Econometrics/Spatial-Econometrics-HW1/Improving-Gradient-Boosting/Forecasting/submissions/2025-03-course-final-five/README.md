# Последние пять сабмитов на март 2025

Распакуйте архив. Отправляйте файл ровно `test.csv` из папок 01–05 по порядку. В проверяющую систему загружается CSV, а не общий ZIP. Сохраняйте имя без суффиксов `(1)` и без дополнительного расширения.

Это новые равновесные смеси готовых прогнозов из предыдущей десятки. Номера в колонке «Компоненты» относятся именно к предыдущей десятке, а не к этому пакету.

A = прежний №04, исходная meta-смесь с WX у XGBoost и обоих LightGBM, 90,83.  
B = прежний №05, тот же состав с правилом среднего/медианы 1,08, 90,83.  
C = прежний №01, WX у XGBoost и LGB приростов, исходный LGB уровней, правило 1,08, 90,82.  
D = прежний №08, WX у XGBoost и LGB уровней, без LGB приростов, правило 1,08, 90,82.  
CatBoost во всех исходных компонентах остаётся базовым.

| Новый № | Компоненты из прежней десятки | Формула | Файл |
| --- | --- | --- | --- |
| 01 | №04 + №05 | Обычное среднее | `01-leaders-equal/test.csv` |
| 02 | №04 + №05 | Логарифмическое среднее | `02-leaders-log-average/test.csv` |
| 03 | №04 + №05 + №01 | Обычное среднее | `03-leaders-plus-01-equal/test.csv` |
| 04 | №04 + №05 + №08 | Обычное среднее | `04-leaders-plus-08-equal/test.csv` |
| 05 | №04 + №05 + №08 | Логарифмическое среднее | `05-leaders-plus-08-log-average/test.csv` |

У двух компонентов равные доли 1/2, у трёх — 1/3. Обычное среднее: mean(p). Логарифмическое: exp(mean(log(1+p)))−1. Усредняются значения прогнозов каждого магазина. Баллы компонентов в формулу не входят.

На момент подготовки итоговые приватные баллы пяти новых смесей были неизвестны; теперь все пять получили 90,83. Ранее сообщённые 90,83/90,82 относятся к компонентам. Пять файлов подготовлены по запросу пользователя как заключительная партия. Повторного обучения и новых пространственных признаков нет.

Проверены SHA источников, соответствие исходным идентификаторам, 18657 строк new_id,rto, положительные конечные прогнозы, размер каждого CSV меньше 1 МБ, UTF-8 без BOM, точное восстановление чисел после записи, отсутствие повторов с предыдущими 36 CSV и внутри пятёрки, CRC архива. Автоматических посылок нет.


## Итог последней партии

Все пять новых смесей получили OK и 90,83 на окончательном приватном рейтинговом датасете. Сопоставление ID с папками предполагает рекомендованный порядок 01→05; все баллы одинаковы, поэтому вывод о результате не зависит от этого порядка. Источник — `contest_results.json`.

Дополнительное усреднение лидеров и добавление компонентов на90,82 не повысило отображаемый максимум90,83. Точные различия MAPE ниже округления неизвестны. Поиск смесей на текущих компонентах завершён по запросу пользователя; новые эксперименты не запускаются.
