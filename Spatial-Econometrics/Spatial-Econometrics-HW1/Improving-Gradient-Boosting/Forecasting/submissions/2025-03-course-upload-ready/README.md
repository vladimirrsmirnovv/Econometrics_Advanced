# Март 2025: файлы с именем test.csv

Распакуйте архив с сохранением папок. Для посылки выберите CSV из нужной папки: его имя должно оставаться ровно `test.csv`, без `(1)`, пробелов и дополнительного расширения. В соревнование загружается этот CSV, а не общий ZIP. Папки разделяют модели и варианты; одинаковые имена файлов не конфликтуют.

В каждой из первых четырёх папок: `01-before` — исходная модель; `02_after_...` — та же модель с учебными WX-признаками. «После» обозначает эксперимент, а не гарантированное улучшение. В подтверждённом ансамбле заменён только LightGBM приростов; остальные три модели оставлены исходными.

Все 11 CSV побайтово совпадают с ранее подготовленными прогнозами. Изменена только упаковка. Деревья, значения прогнозов и метрики не менялись. В каждом CSV 18657 строк, столбцы `new_id,rto`, целочисленные уникальные ID, конечные положительные прогнозы; размер меньше 1 МБ.

Одиночные файлы в пользовательских «Загрузках» имеют суффиксы `(1)`–`(4)`; смеси, которые пользователь сообщил как принятые, таких суффиксов не имеют. Содержимое этих скачанных CSV совпало с исходными файлами по SHA-256. Это указывает на возможную проблему имени при загрузке. Точная причина CE ещё не установлена: нужен текст отчёта проверяющей системы. Принятие нового пакета сервером пока не проверено.

Предоставленный `Downloads/test.csv` содержит один и тот же прогноз `33503980.259272862` для всех магазинов. Это отдельный файл, не один из 11 прогнозов этого пакета; его значения здесь не использованы.
