# Три дополнительных мартовских ансамбля

Уточнение 11 октября: соревнование завершено; баллы относятся к основному финальному мартовскому сету для рейтинга. Точный охват магазинов не подтверждён. Для конкурсного выбора основной критерий — итоговый балл; локальная валидация служит диагностикой. Варианты выбраны после обратной связи этого теста.

Это исследовательские варианты после получения итоговых результатов контеста. Модели не переобучаются; используются исходные формулы из ноутбука. Новые веса и пороги не подбираются. Первоначальный FINAL_DECISION не меняется.

Распакуйте архив с сохранением папок. Отправляйте CSV `test.csv` из выбранной папки, не общий ZIP. Порядок проб соответствует номерам папок:

1. `01-only-xgb-wx-original-mix/test.csv` — WX только у XGBoost; исходная формула ансамбля.
2. `02-all-wx-equal/test.csv` — Все четыре WX-модели; обычное среднее.
3. `03-all-wx-log-average/test.csv` — Все четыре WX-модели; логарифмическое среднее.

Вариант 1 меняет состав: исходные CatBoost и два LightGBM плюс XGBoost с WX kNN12. Он мотивирован улучшением итогового балла одиночного XGBoost на 0,13 балла; локально улучшил январь, но ухудшил февраль.

Варианты 2 и 3 сохраняют все четыре WX-модели, а меняют только усреднение относительно принятой смеси с баллом 90,79. Обычное среднее — сумма четырёх прогнозов / 4; логарифмическое — exp(mean(log(1+prediction)))−1, как original_blends в исходном адаптере.

Ни один из трёх новых вариантов не улучшил исходный ансамбль в обоих контрольных месяцах. Поэтому они предназначены для ограниченной мартовской диагностики и не объявляются подтверждённым улучшением. При подготовке итоговый балл новых вариантов был неизвестен. Месяцы уже изучались; эта проверка не является слепой.

Все CSV: 18657 строк, new_id,rto, ID совпадают с исходными, положительные конечные прогнозы, размер меньше 1 МБ. Точное восстановление чисел после записи и CRC архива проверены. Автоматических посылок в соревнование нет.
