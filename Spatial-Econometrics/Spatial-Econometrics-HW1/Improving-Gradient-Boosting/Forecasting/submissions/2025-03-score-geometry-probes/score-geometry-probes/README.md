# Три пробы весов готовых ансамблей

Все три файла — новые арифметические смеси последней пятерки, где каждый компонент
получил 90,83 на полном мартовском тесте. Модели и признаки не менялись.

| Папка | Веса файлов последней пятерки |
| --- | --- |
| 01_half_U_half_E3 | №01: 1/2; №03: 1/2 |
| 02_half_U_half_E4 | №01: 1/2; №04: 1/2 |
| 03_half_U_quarter_E3_E4 | №01: 1/2; №03: 1/4; №04: 1/4 |

При загрузке выберите **test.csv** внутри соответствующей папки. Общий архив
`score_geometry_probes.zip` сначала распакуйте. Сохраняйте имя `test.csv`.

Из выпуклости MAPE следует: на той же выборке и с той же метрикой отображаемый балл
будет не ниже 90,83, если исходная пятерка действительно является проверенной партией
со скриншота. Точный балл не известен; улучшение не обещается. В проверяющую систему
эти файлы автоматически не отправлялись.

Обоснование, аудит всех доступных попыток и проверка неприменимости точной формулы
RMSLE к MAPE: `Forecasting/score-geometry/README.md`. Прежний итоговый прогноз и отчеты
сохранены.
