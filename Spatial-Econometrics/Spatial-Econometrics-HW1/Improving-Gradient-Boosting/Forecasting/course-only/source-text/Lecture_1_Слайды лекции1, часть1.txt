14Основные темы курсаТема 1. Матрицы весов.Основные концепции пространственного анализа. Понятие соседства. Расстояния. Матрицы весов. Пространственные лаги.Тема 2. Выявление глобальной пространственной зависимости. Глобальные индексы Морана, Гири, Гетиса-Орда. Диаграмма Морана. Двумерный индекс Морана.Тема 3. Выявление локальной пространственной зависимости. Локальные индексы пространственной автокорреляции (LISA): индексы Морана, Гири, Гетиса-Орда. Пространственные кластеры и выбросы. Двумерный локальный индекс Морана. Многомерный локальный индекс Гири.Тема 4. Базовые пространственные модели для данных типа cross-section. Тесты для выявления пространственной зависимости в ошибках регрессии. Модель пространственной автокорреляции (SAR), модель пространственной ошибки (SEM), модель Дарбина (SDM) и др. Выбор между ними.Тема 5. Интерпретация результатов оценивания пространственных моделей. Прямые, косвенные и общие эффекты.Тема 6. Пространственные модели панельных данных. Основные типы пространственно-эконометрических моделей, оцениваемых по панельным данным (SAR, SEM, SDM, динамические пространственные модели панельных данных и др.). Способы оценки этих моделей. Выбор лучшей модели. Интерпретация полученных результатов.Тема 7. Эндогенные взвешивающие матрицы. Особенности оценки моделей с эндогенными взвешивающими матрицами.Тема 8. Географически взвешенные регрессии. Географически взвешенные панельные регрессии. Способы оценки. Представление полученных результатов.Тема 9. Пространственная эконометрика и большие данные.Проблема оценки моделей с пространственными матрицами большой размерности. MESS спецификация.

15Формирование оценки за курс0.5*оценка за домашнее задание + 0.5*оценка за экзаменДомашнее задание выполняется группой из не более 4 студентов; оценивается по шкале 1-10 и состоит из следующих элементов:•постановка содержательной экономической задачи и сбор данных для нее (0-1 балл) ; •написание скрипта с командами для расчетов в одном из статистических пакетов (0-1 балл); •написание отчета с кратким обзором литературы, включением таблиц по результатам оценки моделей, интерпретации полученных результатов, выводами (0-3 балла); •презентацией полученных результатов (0-3 балла); •участие в обсуждении результатов, полученных другими группами студентов (0-2 балла).
