# Выполняемый эксперимент: учебный WX в исходных бустингах

Область: только предоставленный курс. На этом шаге проверяется прямая интеграция пространственных лагов регрессоров WX (блок SLX), с двумя фиксированными матрицами из семинара 4. Другие учебные модели не объявляются проверенными в этом эксперименте.

Источники: `Source/Seminars/Seminar4/municipalities_models.R`: проекция, симметризованные kNN6/12, нормировка W, `lmSLX`; `Source/Seminars/Seminar4/sim_cross_section_models.R`: формула Xβ + WXθ и SLX. Moran используется для диагностики остатков как в семинарах 2–4.

1. Географические единицы — те же 3360 населённых пунктов и 18657 магазинов из исходного X5. Сопоставление координат не меняется. Координаты переводятся в указанную в семинаре Albers Siberia; W фиксирована, симметризована, нулевая диагональ, построчная нормировка. При равных расстояниях используется фиксированный порядок node для воспроизводимости; это техническое разрешение неоднозначности, не дополнительный метод.
2. Для каждого алгоритма WX строится только из его исходных числовых регрессоров. Категории, ID и общие календарные показатели пространственно не усредняются. Для согласования магазинной таблицы с W исходный регрессор усредняется в населённом пункте в данном месяце; затем W умножается на эту таблицу, результат возвращается магазинам. Производные разрывы, усадки, сезонные пакеты и корреляционные графы не добавляются. Обработка NA не подменяется собственным прогнозом.
3. Два кандидата: `wx_knn6`, `wx_knn12`. Во всех fit исходные число деревьев, loss/objective, learning rate, регуляризация и seed сохраняются; early stopping отключена, как в исходном полном submission. CPU остаётся CPU; CUDA XGBoost строго 3.1.3. Перед сравнением выполняется паритет исходного полного ноябрьского fit с сохранёнными результатами.
4. Разработка: август, ноябрь, декабрь 2024. Исходные полные baseline уже сохранены и проверены. Для каждой модели выбирается минимальная средняя MAPE среди двух WX-кандидатов и baseline. Новые кандидаты проверяются на всех трёх месяцах; источники и числа деревьев фиксируются до вычислений.
5. Подтверждение: январь и февраль 2025. Для каждой модели baseline и лучший из двух WX учатся на одинаковой доступной истории с исходными полными числами деревьев, даже если baseline выиграл этап разработки: в таком случае WX остаётся диагностическим экспериментом. WX допускается в итоговый состав только если средняя MAPE разработки ниже baseline и MAPE ниже baseline в обоих месяцах подтверждения. Иначе остаётся baseline. Выбор WX фиксируется до его подтверждающих запусков. Это повторная ретроспективная проверка на уже изученных данных, не новая слепая выборка.
6. Ансамбль имеет исходную формулу `final_meta_logmean`. Новый состав проверяется на январе/феврале; если он не лучше исходного в обоих месяцах, рекомендован исходный ансамбль. Порог1.08, правила смешивания и веса не подбираются заново. Ни один месячный балл leaderboard не используется для обучения, выбора WX или калибровки.
7. На март2025 формируются экспериментальные WX-прогнозы каждой модели с полными исходными числами деревьев, подтверждённый состав и исходный контроль. Если выигрыш не подтверждён, это явно фиксируется; экспериментальный WX не называется улучшением. Число попыток соревнования автоматически не расходуется.
8. Проверки: учебные источники и hashes, сохранность исходных raw/NB/CSV, нулевая диагональ/нормировка W, согласование ID, отсутствие текущей/будущей цели в новых признаках, исходные матрицы временных срезов, CPU/CUDA-паритет baseline, native reload, MAPE пересчитана из CSV, 18657 строк и≤1МБ на submission.

Переход на более сложные учебные спецификации возможен только с прямым источником и настоящей реализацией соответствующей модели. Этот шаг не заменяет SAR/SEM произвольным сглаживанием бустингового прогноза.
