# Полное обучение и мартовские submission

Этот модуль повторяет финальное обучение исходного ноутбука на январе 2023 — феврале 2025. Он использует зафиксированные на валидации изменения; эконометрическая часть репозитория не меняется.

1. `prepare.py` создаёт исходный split `train_val_test` для марта, компактные кэши и новые пространственные признаки. Исторические признаки CatBoost совпадают с ранее измеренными побитово; продолжение гибридных признаков проверено на феврале. Истинная мартовская выручка отсутствует.
2. `train_cpu.py` выполняет исходные и улучшенные полные CatBoost / LightGBM без ранней остановки, сохраняя CSV, native-модели и параметры. Можно выбрать модель и вариант через `--models` и `--variants`.
3. `prepare_gpu.py` готовит приватный Kaggle-ноутбук для двух полных XGBoost 3.1.3 на CUDA. Используются два уже загруженных приватных датасета; новые датасеты не загружаются. Четыре мартовских пространственных признака передаются в сжатом кодовом пакете без будущих фактических исходов. Проверяются идентичность исходных полных матриц и эффективных целей.
4. `import_gpu.py` проверяет два GPU-результата и совпадение исходного мартовского XGBoost с ранее воспроизведённым прогнозом.
5. `assemble.py` сопоставляет все идентификаторы, формирует прежнюю meta-смесь до/после изменений и лучшее исходное правило по валидации, создаёт архив основных CSV и манифест.

Результаты: `Forecasting/submissions/2025-03`. Кэши: `Forecasting/cache/final_2025-03`. Native-модели и выгрузки Kaggle исключены из Git. LightGBM сохраняется через `model_to_string`, чтобы корректно работать с путём Windows, содержащим кириллицу; для загрузки можно передать строку в `lightgbm.Booster(model_str=...)`.

Полные числа деревьев: CatBoost 6 500, LightGBM темпов 7 000, LightGBM уровней 8 000, XGBoost 3 750. Внешняя отправка CSV на leaderboard этим модулем не выполняется.
