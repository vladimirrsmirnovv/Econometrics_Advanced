# Воспроизведение XGBoost на GPU и проверка пространственного улучшения

9 октября 2026 года. В приватном Kaggle-ноутбуке обучены только XGBoost: февральская валидационная модель и финальная модель для марта 2025. Использованы данные и функции из ранее предоставленного `final_solution (1).ipynb`. Все сохранённые метрики XGBoost воспроизведены точно при версии **3.1.3** и устройстве **cuda:0**. Дополнительные найденные ноутбуки для этого результата не понадобились.

Запуск: [приватный ноутбук Kaggle](https://www.kaggle.com/code/vladimirsmirnovve/x5-xgboost-gpu-reproduction-20261009), порядковая версия 4 по ответу API.

| Запуск XGBoost | MAPE, % | Лучшая итерация |
|---|---:|---:|
| Сохранено в исходном ноутбуке | 4,4314600477414245 | 440 |
| Локально, CPU, 3.4.1 | 4,936438075648175 | 796 |
| Kaggle, CUDA, 3.4.1 | 4,915015347615976 | 651 |
| Kaggle, CUDA, 3.1.3 | **4,4314600477414245** | **440** |

В последней строке также точно совпали MAE 3 473 680,084063112, RMSE 7 005 270,650963966 и смещение 2,4043034193846933%. Изменение версии XGBoost существенно влияет на этот расчёт: смена только устройства при 3.4.1 не восстановила исторический результат. Сравнение не устанавливает преимущество GPU над CPU для одной и той же версии 3.1.3: такой CPU-запуск здесь не выполнялся.

Данные и код не менялись между GPU-запусками. Сохранены исходные 21 признак, параметры, обучение до января 2025 и ранняя остановка через 100 итераций без улучшения. Из 466 425 обучающих строк модель использовала 447 768 после исходного исключения строк без конечной цели. Валидация содержит все 18 657 магазинов февраля 2025.

Контроль до обучения подтвердил SHA-256 исходного CSV и ноутбука, точное совпадение матриц признаков обучения и валидации, а также целей float32 и масок исключаемых строк. Максимальное различие обучающих целей float64 между Windows и Linux — 3,55×10⁻¹⁵; после приведения к float32, которое используется XGBoost, различий нет. После выгрузки проверены идентификаторы магазинов, реальные значения РТО, конечность и неотрицательность прогнозов, пересчитаны метрики.

Исходный экспорт указал образ Kaggle 31401 и Python 3.12.13, но не версию XGBoost. Современный запуск использует Python 3.13.15 и Tesla T4; все сохранённые метрики при этом совпали. Поэтому воспроизведение валидационных результатов подтверждено, а побайтовая идентичность исходного контейнера не утверждается. Исходные валидационные прогнозы отдельным файлом не были предоставлены, поэтому сравниваются сохранённые метрики, а не каждый прогноз исторического запуска.

**Пространственное улучшение проверено на восстановленной базе.** Три остальных компонента ансамбля уже воспроизвели сохранённые метрики локально. Они не переобучались; GPU-прогноз XGBoost подставлен в исходные правила смешивания без изменения весов и порога 1,08.

| Февральская валидация | MAPE, % |
|---|---:|
| Исходная схема ансамбля, восстановленный XGBoost | 4,452558454833349 |
| Заменён только CatBoost: добавлена пространственная история | **4,356314198404874** |

Улучшение составляет **0,096244 процентного пункта**, или около **2,16% относительно базовой ошибки**. Сам CatBoost улучшился с 4,730608 до 4,281436%. Эти четыре исторических пространственных признака используют только сведения до t−1. Ранее положительный эффект CatBoost был измерен также на январе 2025 и марте 2024; сравнение полных ансамблей на этих двух месяцах пока использует CPU-XGBoost 3.4.1. Полученный выигрыш относится к февральской валидации, а не к закрытому тесту соревнования. Матрица соседства и исходные параметры выбраны ретроспективно, поэтому результат остаётся исследовательским.

Финальная модель XGBoost обучена с исходными **3 750 деревьями**, независимо от валидационной лучшей итерации 440. Прогноз марта создан для всех 18 657 магазинов. Он сохранён как `results/3.1.3/test_xgboost_log_diff.csv`; это отдельный компонент, а не полный мартовский ансамбль. Исторический мартовский прогноз для сравнения не предоставлен, фактический мартовский РТО отсутствует. Полный ансамбль для марта в этой работе не переобучался, submission в соревнование не отправлялся, public score 90,64 не проверялся.

Основные артефакты: `results/3.1.3/comparison.json`, `gpu_metrics.json`, `feature_checks.json`, `runtime.json`, `ensemble_metrics.csv`, валидационные прогнозы, мартовский CSV и две модели UBJ с контрольными суммами. Результат 3.4.1 сохранён отдельно в `results/3.4.1/`. Общие CUDA-прогнозы в `Forecasting/results/2025-02/` относятся к последнему успешному запуску 3.1.3. Токен в исходный код и загруженный пакет не входит. Исходные эконометрические файлы не изменены.
