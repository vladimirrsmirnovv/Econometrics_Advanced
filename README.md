# Эконометрика

В целом, репозиторий покрывает все тематики в рамках современной эконометрики. Лично мне нравится часть с микроэконометрикой, так как имеется достаточно интересный инструментарий (чего стоят только модели с эндогенным переключением).

Структуризация материала и readme для каждого блока курса будут добавлены позже. Пока что тут практически только итоговые проекты по курсам.
